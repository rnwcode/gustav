# Dokumente

Die drei Planungsdokumente liegen als Artifacts in Claude und sind dort
aktuell. Hier gehört hinein, was im Repo versioniert sein muss:

- `specs/` — eine Spec je Funktion, bevor Code entsteht (Regel 7 in CLAUDE.md)
- `datenmodell.md` — Modell, Zustandsübergänge, Planer-Regeln
- `bauplan.md` — Phasen, Testebenen, Definition of Done

## Spec-Vorlage

Siehe `specs/_vorlage.md`. Eine Spec ist fertig, wenn daraus ein
fehlschlagender Test geschrieben werden kann — nicht vorher.
